# HIGH TECH PS - Jailbreak Host

واجهة مستخدم حديثة وموحدة لتشغيل ثغرات وتعديلات أجهزة PlayStation عبر المتصفح مع دعم كامل للتخزين الأوفلاين (Offline Caching).

---

## 🌟 المميزات

* **واجهة موحدة:** تحتوي على زر فرعي ومركزي واحد لتشغيل التعديلة بسلاسة.
* **دعم العمل بدون إنترنت (Offline):** متوافق مع نظام التخزين المؤقت **AppCache** و **Service Worker**.
* **تصميم عصري ومتجاوب:** تصميم متوافق مع شاشات المتصفح على أجهزة PlayStation والهواتف والمكتب.
* **شاشة سجل وتنبيهات (Console):** لعرض حالة الكاش وخطوات تفعيل الثغرة بشكل مباشر.

---
